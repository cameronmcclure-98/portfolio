# Portfolio: deployment

1. Replace the contents of your GitHub Pages repository with this folder: `index.html` and the `assets/` folder.
2. Keep the folder structure as it is. Images live in `assets/img/`, PDFs in `assets/docs/`.
3. Commit and push. The site updates within a minute or two.

All images that were previously embedded inside index.html are now separate files in assets/img/, so the page loads much faster.
